# 같이놀개 M1 상태 전이

## Pet

| 현재 | 사건 | 다음 | `deleted_at` | 부수효과 |
|---|---|---|---|---|
| 없음 | 직접 등록 Commit | ACTIVE | NULL | 내부 `firstPetCandidate` 확정 |
| ACTIVE | 관리자 정지 | SUSPENDED | NULL | Active Pet이면 `users.active_pet_id=NULL` |
| ACTIVE | 일반 삭제 | DELETED | 현재 시각 | Friendship 삭제·양방향 PENDING 요청 취소 |
| SUSPENDED | 일반 삭제 | DELETED | 현재 시각 | Friendship 삭제·양방향 PENDING 요청 취소 |

`status = DELETED ↔ deleted_at IS NOT NULL`은 양방향 불변조건이다.
`ACTIVE`, `SUSPENDED`는 `deleted_at=NULL`이고 최대 5마리 한도에 포함한다.
삭제 Pet 복구는 M1에 없다.

## First Pet Active Assignment

| 생성 결과 | Active 지정 사건 | 결과 | Pet 생성 Commit |
|---|---|---|---|
| `firstPetCandidate=true` | Active 지정 성공 | ASSIGNED | 유지 |
| `firstPetCandidate=true` | Active 지정 실패 | RETRY_REQUIRED | 유지 |
| `firstPetCandidate=false` 또는 기존 Active 존재 | 지정 미실행 | NOT_APPLICABLE | 유지 |

Pet 생성과 Active 지정은 독립 트랜잭션이다. Active 지정 단계는 Pet 수를 다시 세어
첫 Pet 여부를 추정하지 않고 생성 단계의 내부 후보값만 사용한다.

## Registration Attempt

| 현재 | 사건 | 다음 |
|---|---|---|
| 없음 | 동기 Provider 요청 시작 | PENDING |
| PENDING | canonical 등록번호 확인 | SUCCEEDED |
| PENDING | 정보 불일치 또는 canonical 번호 없음 | REJECTED |
| PENDING | timeout·Provider 장애 | FAILED |
| SUCCEEDED | Pet에 적용 | CONSUMED |
| PENDING 또는 SUCCEEDED | 유효기간 경과 | EXPIRED |

consume은 `SUCCEEDED`에서만 허용하며 중복 consume은 `409` 상태 충돌이다.

## Greeting

| 현재 | 사건 | 다음 | 부수효과 |
|---|---|---|---|
| 없음 | 최초 인사 | SENT | DIRECT 방·Participant·최초 TEXT 생성 |
| SENT | 상대 최초 답변 | RESPONDED | 이후 자유 대화 |
| SENT | 24시간 무답 | EXPIRED | 신고 없으면 방·Participant·메시지 물리 삭제 |

`EXPIRED`는 종결 상태이며 재인사는 허용하지 않는다.

## ChatRoom

| 현재 | 사건 | 다음 |
|---|---|---|
| ACTIVE | 답변한 비친구 방 30일 무활동 | ARCHIVED |
| ARCHIVED | 정상 메시지 전송 | ACTIVE |

무답 Greeting 방은 별도 상태로 전환하지 않고 삭제한다.
차단은 Room 상태가 아니라 UserBlock 관계로 검사한다.

## FriendRequest

| 현재 | 사건 | 다음 |
|---|---|---|
| 없음 | 요청 | PENDING |
| PENDING | 상대가 반대 방향 요청 | ACCEPTED |
| PENDING | 수락 | ACCEPTED |
| PENDING | 거절 | REJECTED |
| PENDING | 발신 취소 | CANCELED |
| PENDING | 7일 경과 | EXPIRED |

`ACCEPTED` 전이 시 Friendship 한 행을 생성한다.

## Friendship

Friendship은 상태 enum을 두지 않는다. 정렬 Pet pair 행의 존재가 친구 관계다.
삭제 시 기존 ChatRoom과 Message는 유지한다.

## MeetingCard

| 현재 | 사건 | 다음 |
|---|---|---|
| 없음 | 필수값 확인 후 확정 | OPEN |
| OPEN | 참여 Pet 중 한쪽이 취소 | CANCELED |

M1에서는 수정·복구가 없다.

## Report

| 현재 | 사건 | 다음 |
|---|---|---|
| 없음 | 신고 접수 | OPEN |
| OPEN | 관리자 경고 | ACTIONED |
| OPEN | 관리자 기각 | NO_ACTION |

신고 접수만으로 차단하지 않는다.
`ACTIONED`, `NO_ACTION`은 종결 상태이며 추가 조치를 허용하지 않는다.

## UserBlock

M1에서 생성만 가능하며 해제 상태 전이는 없다. 행 존재가 차단 상태다.
