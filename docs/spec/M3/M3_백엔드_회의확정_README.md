## 공통 완료선

- 각 기능의 API·DB·오류·권한 계약이 문서와 일치한다.
- DIRECT REST/WebSocket과 Open Chat Kafka/Consumer의 메시지 형태가 일치한다.
- Media와 Setlog 공유는 ID를 정본으로 참조하며 만료 URL을 DB에 저장하지 않는다.
- 위치·위험 신호·관리자 원문 조회의 개인정보 범위와 보존 정책을 지킨다.
- 8월 25일까지 배포 환경 통합 테스트를 마치고 8월 26일 코드를 동결한다.
